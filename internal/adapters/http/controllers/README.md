# Controllers

Здесь лежат объекты взаимолействия с внешним миром. 
Они напрямую пробрасываются  в http сервер.
Каждый метод обрабатывает один запрос. Контроллеры 
управляют UseCase-ами. Их задача состоит в том, чтобы 
получить данные из http запроса, вызвать соответствующий 
useCase, преобразовать данные к httpResponse.
