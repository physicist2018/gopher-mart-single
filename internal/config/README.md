### Описание функций и структуры:

1. **Configuration**:
    - Структура, содержащая конфигурационные параметры приложения:
        - `RunAddress`: Адрес интерфейса, на котором запускается сервер.
        - `DatabaseURI`: Параметры подключения к базе данных.
        - `AccrualSystemAddress`: Адрес системы расчёта начислений.

2. **NewConfiguration**:
    - Создает новый экземпляр `Configuration` с значениями по умолчанию.
    - Регистрирует флаги командной строки для каждого поля структуры.

3. **LoadConfig**:
    - Загружает конфигурацию из флагов командной строки и переменных окружения.
    - Возвращает указатель на `Configuration` и ошибку (в данном случае всегда `nil`).

4. **Parse**:
    - Парсит флаги командной строки и переменные окружения.
    - Переменные окружения имеют приоритет над флагами командной строки.

5. **String**:
    - Возвращает строковое представление конфигурации.
    - Полезно для логирования или отладки.

### Примечания:
- **Флаги командной строки**:
    - `-a`: Адрес интерфейса (по умолчанию `localhost:8080`).
    - `-d`: Параметры подключения к базе данных.
    - `-r`: Адрес системы расчёта начислений.
- **Переменные окружения**:
    - `RUN_ADDRESS`: Переопределяет `RunAddress`.
    - `DATABASE_URI`: Переопределяет `DatabaseURI`.
    - `ACCRUAL_SYSTEM_ADDRESS`: Переопределяет `AccrualSystemAddress`.
