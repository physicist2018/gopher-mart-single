### Описание функций и структуры:

1. **UserIDKey**:
    - Тип, используемый для хранения идентификатора пользователя (`userID`) в контексте запроса.
    - Это пустая структура, которая служит ключом для доступа к `userID` в контексте.

2. **JWTAuthMiddleware**:
    - Создает middleware для аутентификации пользователя с использованием JWT-токена.
    - Принимает `tokenService` (сервис для работы с JWT-токенами) и возвращает middleware.
    - Middleware выполняет следующие действия:
        - Извлекает токен из заголовка `Authorization` или куки `token`.
        - Проверяет наличие токена. Если токен отсутствует, возвращает ошибку `401 Unauthorized`.
        - Валидирует токен с помощью `tokenService`. Если токен невалиден, возвращает ошибку `401 Unauthorized`.
        - Добавляет `userID` (извлеченный из токена) в контекст запроса.
        - Передает управление следующему обработчику в цепочке.

### Примечания:
- **Формат заголовка Authorization**:
    - Ожидается строка в формате `Bearer <token>`. Например: `Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...`.
- **Куки**:
    - Если токен не найден в заголовке, middleware проверяет куку с именем `token`.
- **Контекст запроса**:
    - `userID` добавляется в контекст запроса с ключом `UserIDKey{}`. Это позволяет последующим обработчикам получить доступ к `userID`.
